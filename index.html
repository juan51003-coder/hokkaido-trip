  • 確認北海道雪地自駕租車訂單（4WD、雪胎、ETC 卡與全險） 1/12 14:00 新千歲機場取車，1/18 機場還車
  • 預約富良野起司工房 DIY 體驗時段 預計 1/14 10:30~12:00 進行手作體驗
  • 填寫 Visit Japan Web 入境與海關申報 QR Code 出發前 6 小時以上完成登錄並截圖備用
  • 投保旅遊平安險＋海外突發疾病險（含雪地活動保障） 確認包含海外醫療專機與自駕相關保障

出發前 24 小時最終確認

確認進度 0 / 0
  • 護照正本（效期 6 個月以上）＋ 台灣駕照正本 ＋ 日文譯本 缺一不可，建議放在隨身拉鍊袋
  • 虎航 IT260 線上報到 / 確認托運行李額度 06:00 抵達高雄機場，預留冬季厚重衣物重量額度
  • 開通日本漫遊 / 安裝 eSIM 並測試設定 自駕導航 Google Maps 與聯絡民宿必備
  • 離線儲存住宿地址、MapCode 與緊急聯絡電話 山區或雪地訊號不穩時可直接輸入車機導航
  • 行動電源與備用電池全數放入「隨身手提行李」 嚴禁托運！低溫環境手機掉電快，建議多帶一顆備用
  • 家中門窗、瓦斯、非必要電源關閉與垃圾清理
